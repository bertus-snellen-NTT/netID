About netID

A comprehensive research tool for network identifiers.

What is netID?

netID is a web-based tool designed to help network engineers, security researchers, and IT professionals quickly research and validate IP addresses, MAC addresses, and BGP Autonomous System numbers.

The application provides a clean, intuitive interface with discrete functions for each type of network identifier, making it easy to find the information you need.

IP Address Tools
  • Validation: Check if an IP address is valid (IPv4 or IPv6)
  • Reverse DNS: Perform reverse DNS lookups
  • Geolocation: Get geographic information (requires API)
  • Network Info: Calculate network ranges and broadcast addresses
MAC Address Tools
  • Validation: Check MAC address format validity
  • Info: Get detailed MAC address information
  • Formatting: Convert between different MAC formats
  • Vendor Lookup: Identify the manufacturer from OUI
BGP AS Tools
  • Validation: Check if an AS number is valid
  • Info: Get detailed AS information
  • Prefixes: View IP prefixes announced by an AS
  • Peers: View BGP peers for an AS
  • AS Path: View sample AS paths

Architecture

netID follows a modular architecture with clear separation of concerns:

  • Services Layer: All business logic is contained in the app/services/ directory with discrete functions for each operation
  • Routes Layer: Flask blueprints in app/routes/ handle HTTP requests and responses
  • Templates: HTML templates in app/templates/ provide the user interface
  • Static Files: CSS and JavaScript in app/static/ for styling and client-side functionality

This architecture ensures that:

  • Each function has a single responsibility
  • Functions are easily testable and maintainable
  • The codebase is easy to extend with new features
  • Dependencies between components are minimized

Technologies Used

Backend
  • Flask: Web framework
  • Python: Programming language
  • ipaddress: IP address manipulation
  • socket: Network operations
Frontend
  • Bootstrap 5: CSS framework
  • HTML5: Markup language
  • Jinja2: Template engine
